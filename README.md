# Sistema de Control de Inventario y Ventas

## Descripción

Sistema desarrollado para facilitar el control de los productos, el inventario y las ventas de un negocio.

Su propósito principal es mantener organizada la información de los productos y permitir registrar las ventas realizadas, ayudando a conocer de forma sencilla las existencias disponibles.

## Funciones principales

- Registrar productos.
- Consultar y actualizar productos.
- Controlar las existencias del inventario.
- Registrar ventas.
- Actualizar el inventario después de cada venta.
- Consultar la información registrada.

## Objetivo

Facilitar la administración del inventario y las ventas mediante un sistema sencillo, organizado y fácil de utilizar.
